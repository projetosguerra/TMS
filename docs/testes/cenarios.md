# Cenários de teste

Estrutura inicial para os cenários RF01–RF06, detalhados na Etapa 7. Os testes xUnit de domínio pertencem à Etapa 3.

## Modelo de registro

- Identificação
- Requisito funcional
- Pré-condições
- Dado
- Quando
- Então / resultado esperado
- Resultado obtido
- Situação
- Evidência e figura/documento
- Data e responsável pela execução
